# WattWise – Energy Waste Audit Portal

**WattWise** is a web-based portal designed to help users track, audit, and analyze energy consumption to identify waste and optimize power usage efficiently.

**Presentation Link:** https://www.canva.com/design/DAHWCGqeVas/_2aWPVOkFOPJXEq1WZPlKg/edit

---

## 🚀 Features

- **Energy Consumption Tracking:** Monitor power usage across devices and appliances.
- **Waste Identification:** Pinpoint inefficient energy usage and peak consumption hours.
- **Audit Reports:** Generate insightful summaries to guide energy conservation.
- **Interactive UI:** Fast, responsive interface powered by React and Vite.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, HTML5, CSS3
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Deployment:** GitHub Pages / CI/CD Actions
